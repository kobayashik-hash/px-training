# 英字向けWeb画面を日本語化して文字被りを防ぐ

## 再利用できる手順

- 表示文言を日本語へ置き換える前に、英字向けに設定された `line-height` と `letter-spacing` を洗い出す。日本語フォントは文字高が大きく、同じ値でも上下行が重なりやすいため。
- 見出しは意味単位で `span` に分け、PCとスマホで改行位置を固定する。単純な自動折り返しに任せると縦長や不自然な分割が起きる。
- Chrome DevTools Protocolで320/390/768/1024/1440pxを再現し、各行の文字矩形を計測する。前行の下端より次行の上端が下にあることを確認すれば目視だけより確実。
- 画面全体の `scrollWidth` と `innerWidth` も同時確認し、文字被りを直した結果の横はみ出しを防ぐ。
- UIの英字を日本語化する際は、固有のゲーム名だけを残し、操作名・章名・部品名・エラー文を一貫して訳す。

## 会社環境の制約と回避策

- 通常のヘッドレスChromeは指定したスマホ幅と内部幅が一致しない場合があるため、端末幅を明示的に上書きして検証した。
- Chrome検証用プロファイルは通常権限で削除できない場合があるため、対象プロセスと絶対パスを確認してから権限付きで削除する。

## 効かなかった / 遠回りだった試行

- 英字用の詰まった行間を少しだけ広げた → 日本語フォントの実際の文字高を下回り被りが残った → 文字座標を測って正の行間が出る値まで調整した。
- 通常の幅指定だけでスマホ撮影した → 内部表示幅が異なり正しい判定にならなかった → 端末エミュレーションで幅を固定した。
