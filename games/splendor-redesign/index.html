GAME 01 / 宝石の煌めき × 成長の連鎖

宝石を集め、
商いを広げ、
威信を築け。

買うほど、次の一手が強くなる。

2–4人
30分
15点で勝利
遊び方を見る↓

01 / ひと目でわかる

勝利は、
連鎖から生まれる。

宝石をカードへ変え、購入力を育てる。カードと貴族で15点を先に築こう。

  1. 宝石を集める
  2. ◆カードを買う
  3. −1次が安くなる
  4. 15威信を築く

02 / ゲームの準備

人数を選んで、
場をつくる。

何人で遊ぶ？
発展カード各レベル4枚計12枚を表向きに
貴族5枚プレイヤー数＋1枚
各色の宝石7個金貨は5個すべて
最初の人最も若い人時計回りに進める

03 / あなたの手番

4つから、
1つだけ。

タップすると条件を確認できます。

異なる3色を
1個ずつ

アクション 01

異なる3色を1個ずつ取る

場にある宝石から、違う色を3個まで取ります。

金貨はこの方法では取れません。

04 / いちばん大事な仕組み

買うほど、
次が安くなる。

買ったカードは、同じ色の支払いを永久に1つ減らします。

青3個が必要なカードなら

青カード0枚→青宝石 3個
青カード1枚→青宝石 2個
青カード2枚→青宝石 1個

カードは3か所だけ見る

得点・コスト・色。

  • 左上威信点
  • 左下支払う宝石
  • 右上永久ボーナスの色

盤面を見渡す。

自分のカードだけを見るな。盤面は静かに、次の一手を語っている。

03今の得点か、

06 / 終わり方と確認

15点で、
最終ラウンド。

15威信点

誰かが15点以上になったら、そのラウンドまで全員が同じ回数だけ手番を行います。最高得点が勝者です。

同点なら、購入した発展カードが少ない人。それも同じなら同率勝利。

迷ったときだけ開く

宝石は何個まで持てる？

金貨を含めて最大10個。超えた分は手番の最後に返します。

金貨はどう使う？

予約したとき、場に残っていれば1個獲得。支払いでは好きな色1個の代わりになります。

買ったカードは補充する？

購入・予約したら、同じレベルの山札からすぐに1枚公開します。

予約は何枚まで？

最大3枚。公開カードか山札の一番上を予約でき、捨てることはできません。

貴族はどうやって取る？

購入済みカードだけで条件を満たすと自動で訪れます。1手番に1枚までです。

準備はできた
